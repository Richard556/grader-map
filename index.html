Administration

🔒

Admin access

Enter the township admin PIN.

Grading cycle

How long a graded road stays green, then yellow, before it shows as overdue.

Reset roads to untouched

Turns roads back to dashed gray to start a new cycle. Town streets are never touched. Every reset is recorded in the history.

Delete road history

Removes entries from the change history (and from reports). Road colors on the map don't change.

Delete grader sessions

Removes finished check-in sessions. Whoever is in the grader right now is never affected.

Hazard pins

Select pins to remove from every device, along with their photos.

Drivers

The shared list every device sees at sign-in. New names join automatically the first time someone signs in. Removing a name only takes it off the list — their history stays.

GPS auto-blade

When an operator turns auto-blade on, roads are tracked as the grader covers them at blading speed. These settings apply to every device.

Change admin PIN

Protection

The PIN is checked on the server, never stored in the app. After 5 wrong PINs in 15 minutes, admin access locks for 15 minutes.
